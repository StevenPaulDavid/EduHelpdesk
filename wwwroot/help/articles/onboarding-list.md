**Onboarding** lists new staff and everything being got ready for them. Each onboarding is also a ticket, so IT's tasks show in the ticket list too (under **Tickets → Onboarding**).

## Views

| Tab | Onboardings |
| --- | --- |
| In progress | Started and not finished |
| Not started yet | Their start date is still to come |
| Overdue tasks | With a task past its due date |
| IT tasks left | With IT tasks still to do |
| Finished | Every task done |
| All | Everything, cancelled ones included |

## Filters

Narrow by when they're **starting**, which **checklist** they were started from, **department** and **technician**, and choose how to sort the list.

## The columns

Each row shows the new starter, their **start date**, **progress** (tasks done of the total), **IT tasks left**, the status and the onboarding's ticket number.

**New onboarding** starts one. See [The onboarding page](onboarding-page).
